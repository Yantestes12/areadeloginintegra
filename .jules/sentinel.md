## 2024-05-24 - [Fix DOM XSS in file upload]\n**Vulnerability:** DOM-based Cross-Site Scripting (XSS) in `matricula.html` via unsafe use of `innerHTML` with uploaded file names (`f.name`).\n**Learning:** The frontend directly concatenates user-provided file names into HTML strings for rendering, creating an injection vector.\n**Prevention:** Use `document.createElement` and `textContent` instead of `innerHTML` when dynamically constructing DOM elements with user input.
